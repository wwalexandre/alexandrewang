Sanofi2026

Monthly data files saved and prepared on their own

Problem
Every month the ODR report files arrived by email, and someone had to download, rename, find the right folder and clean up the sheets before closing.
Solution
A flow that takes only the Excel file from the email, saves it to the previous month's SharePoint folder with a standard name and runs an Office Script that gets the file ready for the dashboard.
Result
The file is in the right place as soon as the email arrives, in the same format every month. The same pattern became a second flow, for the R&D TOP 20 file.

What I learned

The file reached SharePoint empty because the flow saved only the attachment name. The fix was to save the content, converted from base64. And the folder is calculated from the date, so the flow needs no monthly changes.

// previous month, for the folder and the file name
formatDateTime(addDays(startOfMonth(utcNow()), -1), 'MM')

// the attachment content, not just its name
base64ToBinary(items('Apply_to_each')?['contentBytes'])

Alert for orders without picked material

Problem
Released production orders sat waiting for material, and nobody knew in time to keep the line from stopping.
Solution
A flow that checks released orders and alerts the team on Teams when one goes past 1 hour with no material picked.
Result
The team acts before the line stops. The alert was recognized by the company.

What I learned

A good alert only speaks when someone needs to act. The message already says which order, on which line and how long it has been waiting, so the team can act without digging.

Patterns I repeat

  • Trigger on the event when possible. The data file flow runs when the email arrives, not at a fixed time.
  • Calculated dates, not typed ones. Folder and file name come from today's date, so nobody has to touch the flow every month.
  • Alert only when someone needs to act. The Hypera alert stays quiet until an order goes past 1 hour.
  • Document and hand over. At Sanofi the flows ran on my account. Before leaving, I documented each one and handed them over to the team.
