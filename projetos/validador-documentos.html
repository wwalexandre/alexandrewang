Validador de documentos de importação

Antes de liberar um embarque, alguém precisa conferir se invoice, packing list, shipping list e certificados de análise contam a mesma história. Escrevi um script em Python que faz essa conferência, inclusive em documentos escaneados, e entrega um relatório pronto.

Python · pandasPyMuPDFTesseract OCR · OpenCVDemo com dados fictícios

Por que isso importa

Comércio exterior é uma cadeia de prazos. Uma quantidade que não bate, um lote repetido ou uma validade curta descoberta tarde vira carga parada no terminal, custo de armazenagem e risco de faltar produto na ponta.

A conferência manual cruza quatro ou cinco documentos linha a linha. É lenta, cansativa e depende de quem está conferindo naquele dia.

Como funciona

Três níveis de resultado

  • FALHA divergência que precisa voltar para o fornecedor antes de aprovar.
  • ATENÇÃO ponto para conferir no olho, por exemplo uma leitura duvidosa do OCR.
  • OK a checagem passou.

Trechos da lógica

Versões simplificadas, escritas para esta página, de duas partes do script.

Ler a página: texto direto ou OCR

def texto_da_pagina(pagina):
    texto = pagina.get_text()
    if len(texto.strip()) > 50:          # PDF digital: o texto já está lá
        return texto
    pix = pagina.get_pixmap(dpi=300)      # PDF escaneado: vira imagem
    img = np.frombuffer(pix.samples, np.uint8).reshape(pix.h, pix.w, pix.n)
    cinza = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)
    _, pb = cv2.threshold(cinza, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    return pytesseract.image_to_string(pb)

Validade mínima e fabricação recente

def checar_validade(lote, data_chegada, meses_min=18, meses_fab_max=6):
    restantes = meses_entre(data_chegada, lote.validade)
    if restantes < meses_min:
        return "FALHA", f"Lote {lote.numero} chega com {restantes} meses (mínimo {meses_min})"
    if meses_entre(lote.fabricacao, data_chegada) > meses_fab_max:
        return "ATENCAO", f"Lote {lote.numero} fabricado há mais de {meses_fab_max} meses"
    return "OK", f"Lote {lote.numero} dentro do prazo"

O que aprendi

  • OCR erra de formas previsíveis. Letra O vira zero, I vira 1, carimbo colorido vira ruído. Por isso a leitura duvidosa vira ATENÇÃO, não FALHA.
  • Cache por página faz diferença. Rodar de novo depois de corrigir um documento leva segundos, porque só as páginas novas passam pelo OCR.
  • A data da invoice nem sempre é a data do embarque. A data real de saída fica no conhecimento de transporte, e isso muda a conta da validade.

Sobre o código: o script original trabalha com documentos reais de fornecedores e não é público. Os trechos e o relatório desta página foram recriados com dados fictícios.
